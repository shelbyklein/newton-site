# Newton

[Visit the Newton microsite](https://shelbyklein.github.io/newton-site/).

This repository contains the published static product-preview website for Newton: persistent AI teammates, independent routine workers, project Boards, Huddle, Reporting, connections, and a phone companion. Codex CLI and Claude Code are joined by the Gemini integration preview and optional experimental Hermes runtime. Demo captures contain sample data.

The page is published from the root of the main branch using GitHub Pages. It contains only the website and its public assets. Newton's desktop application is maintained separately.

The DM Sans font license is included in fonts/LICENSE.txt.
