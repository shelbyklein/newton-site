# Newton

[Visit the Newton microsite](https://shelbyklein.github.io/newton-site/).

This repository contains the published static product-preview website for Newton, a local macOS home for persistent Codex and Claude teammates.

The page is published from the root of the main branch using GitHub Pages. It contains only the website and its public assets. Newton's desktop application is maintained separately.
